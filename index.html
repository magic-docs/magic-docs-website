Microsoft apps

Magic Docs original apps - available from the Microsoft Store

Docs Indexer

Docs Indexer helps you turn Markdown and text documents into a structured, searchable fact database. It scans your files, extracts key information with AI, and organizes the results locally so you can review, reuse, and manage knowledge more efficiently.

Docs Builder

Docs Builder converts your source files into documentation written in Markdown. The app uses your selected AI provider to extract key facts from your files into a local database and then to generate polished, structured documentation with images and tables.
